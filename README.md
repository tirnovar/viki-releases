# VIKI releases

Download page for **VIKI**, a local AI command center over an Obsidian vault (voice & text).

- **Platform:** macOS 14 or newer on Apple Silicon (M1 and later). Intel Macs are not supported.
- **Download:** the newest `.dmg` is under [Releases](https://github.com/tirnovar/viki-releases/releases/latest).
- **Requirements and setup:** the onboarding guide ships inside the app (Settings → Info) and with each release.
- **Source code** lives in a private repository. Issues and questions: [Discussions](https://github.com/tirnovar/viki-releases/discussions).

`latest.json` on each release describes the newest version for the in-app update check:

```json
{ "version": "0.8.0", "dmg_url": "https://github.com/tirnovar/viki-releases/releases/download/v0.8.0/VIKI_0.8.0_aarch64.dmg", "sha256": "…", "notes_url": "https://github.com/tirnovar/viki-releases/releases/tag/v0.8.0", "published_at": "2026-09-21T00:00:00Z" }
```
